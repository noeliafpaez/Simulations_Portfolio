# Simulations_Portfolio
# 🧪 Chemical Engineering Process Simulations

In chemical engineering, **process simulations** use mathematical models to replicate industrial operations within a computer program. These models are essential for predicting behavior, running estimations, and optimizing process performance. 

This repository contains interactive Jupyter Notebooks demonstrating various chemical engineering simulations built with Python.

## 🛠️ Built With
* **NumPy** – Numerical computing and mathematical modeling
* **Pandas** – Data manipulation and analysis
* **Matplotlib** – Data visualization and process plotting
